Install as model-driven app pages

In a development Power Platform environment, open an unmanaged solution; add the HTML web resource files using names such as mgt_/metadata.html; add the resources to model-driven app navigation; publish and verify user permissions.

Installation guide ↗

Network transparency

The public website fetches Mightora shared UI, its logo and js-yaml. Downloaded resources use inline JavaScript/CSS and connect to the Dataverse API only when running inside an authenticated model-driven application.

To verify activity yourself, open browser Developer Tools (F12), choose Network, enable Preserve log and reload. These tools are not independent offline Dataverse clients. No security certification is claimed.
