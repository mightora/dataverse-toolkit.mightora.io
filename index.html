Network transparency

The public website loads Mightora shared UI, its logo, js-yaml and Cloudflare Web Analytics. Cloudflare measures visits and website performance but is not included in downloaded Dataverse web resources. These tools communicate only with your authenticated Dataverse environment. Plugin traces, records and tenant credentials are not intentionally sent to Cloudflare.

To verify activity yourself, open browser Developer Tools (F12), choose Network, enable Preserve log and reload. These tools are not offline Dataverse clients. Web Analytics pageviews do not by themselves reliably count direct file downloads. No security certification is claimed.
