Installation and deployment

In Power Apps, add mgt_/migration.html as an HTML web resource to your unmanaged solution. Add it as a page in the model-driven app designer. Deploy the same resource to the source and destination environments using your normal ALM pipeline.

The public GitHub Pages preview runs in sample mode and cannot access an authenticated Dataverse environment. Host-embedded web resources use only same-origin Web API calls and never load third-party JavaScript or Cloudflare analytics. Do not use this to move live customer data until verified in a development tenant.
